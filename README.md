## ◢ what I build

- **☁️ Multi-cluster EKS fleet** — one cluster per workload class (general · AI/GPU · data · security · regulated) × environment, each with its own VPC, KMS, DNS and Terraform state.
- **🔀 GitOps at scale** — Argo CD as an in-cluster capability; `ApplicationSets` roll add-ons and tenant workloads to every cluster, each self-reconciling with **no central hub**.
- **🕸️ Zero-trust mesh** — Istio + Envoy sidecars for **mTLS**, `AuthorizationPolicy`, and Envoy **ext-authz → OPA that fails closed**; ingress behind NLB/ALB, CloudFront and WAF.
- **🤖 Agentic & GenAI** — agents on **Bedrock AgentCore** with the **Strands Agents SDK**, internal APIs exposed as **MCP tools** through AgentCore Gateway with least-privilege access.
- **🧠 MLOps** — real-time & batch inference on **SageMaker** + Lambda; pipelines with SageMaker, EventBridge and CodePipeline that **cut deployment time 50%**.
- **⚡ Scale & HPC** — **Karpenter** (on-demand/Spot/GPU) and **AWS ParallelCluster** for large scientific compute.
- **🛡️ Guardrails** — OPA Gatekeeper, restricted Pod Security, default-deny network policies, IRSA, tenant quotas.
